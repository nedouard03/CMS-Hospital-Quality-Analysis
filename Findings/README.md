# Findings

Summary documentation of the analysis methodology, results, and data quality process.

## Files

**CMS Hospital Quality Analysis Findings Summary.pdf**
A summary covering the project's problem statement, methodology, key insights, and implications. This is the primary takeaway document for anyone wanting a quick overview of what the analysis found without reviewing the underlying SQL or dashboard.

**CMS Hospital Quality Analysis Change Log.pdf**
Documentation of data quality issues identified in the raw CMS datasets and the resolution applied to each, including handling of missing rating values, inconsistent formatting, and data type corrections.

## Summary of Key Insights

1. The Midwest outperforms all other regions on overall quality rating (3.28) and patient survey rating (3.30); the South underperforms at 2.97
2. Veteran Health Administration hospitals outperform all other ownership types; government-owned and proprietary hospitals show the weakest clinical performance
3. Patient survey data coverage is strong nationally — only Mississippi falls below 80% coverage among rated hospitals
4. 10 states are flagged High Risk using a composite model of low-star concentration combined with below-national-average mortality and safety performance

See the full summary PDF in this folder for complete methodology and implications.
