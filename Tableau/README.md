# Tableau

Interactive dashboard visualizing the CMS hospital quality analysis.

## Files

**CMS_Hospital_Quality_Dashboard.twbx**
Tableau packaged workbook containing all dashboard sheets and underlying data connections. Open with Tableau Desktop or Tableau Public to interact with the full dashboard.

**dashboard_screenshot.png**
Static image of the published dashboard for quick reference without opening Tableau.

## Live Version

The dashboard is also published online and viewable without any software:
[[View on Tableau Public](https://public.tableau.com/views/Copy_17826017627110/Dashboard2?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)]

## Dashboard Contents

- KPI summary cards: total hospitals analyzed, national average rating, count of High Risk states, and HCAHPS survey coverage gap
- Regional quality comparison chart
- Combined state-level risk and HCAHPS coverage map
- Ownership type performance comparison
- National quartile distribution chart

## Tools

Built in **Tableau Public**, connected to cleaned CMS data exported from BigQuery.
